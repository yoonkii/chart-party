# 차트 파티 (Chart Party) — GDD v1.1 (as-built)

> **한 줄 피치**: 전원이 똑같은 실제 주식 차트를 받는다. 1년치가 5분에 재생된다. 판단력만으로 갈린다.
>
> 장르: 멀티플레이어 캐주얼 파티게임 × 모의투자 · 매치 길이 ~30분 (6차트 리그전)
> 상태: **v0.3 구현 완료** — 방 코드 기반 실시간 멀티(최대 8인, 봇 자동 충원) + 솔로 봇전
> 플레이: https://yoonkii.github.io/chart-party/ · 리포: https://github.com/yoonkii/chart-party

이 문서는 초기 기획(GDD v0.1)이 아니라 **실제로 구현된 게임**을 기술한다.
기획 대비 달라진 지점은 ⚡ 표시로 명기한다.

## 1. 핵심 컨셉

### 1.1 구조적 훅: Duplicate 방식
- 모든 플레이어가 **같은 차트, 같은 시작 자본, 같은 의사결정 타이밍**을 받는다.
- 현실 투자에서 불가능한 조건 → 운 논란 원천 차단, 순수 판단력 대결.
- 차트는 실제 종목의 과거 1년치 — 정산 때 정체가 공개되며 "아 그때 그 차트!"라는 서사가 붙는다.

### 1.2 포지셔닝
| 기존 | 한계 | 본 게임 |
|---|---|---|
| 증권사 모의투자 | 실시간, 한 판에 수 주 | 1년치를 5분에 압축 |
| chartgame류 | 싱글 | 동시 대전 + 관전 텐션 |
| 코인 그래프 게임(사행성) | 순수 운/조작 | 실제 역사 데이터, 스킬 점수화 |

### 1.3 톤
- 캐주얼 파티. 경마 중계의 텐션 + 정산 순간의 굴욕과 웃음.
- 비주얼 방향: **"미드나이트 터미널 × 증권방송 스코어보드"** — 직각 모서리, 헤어라인,
  모노스페이스 대문자 라벨, 하드 오프셋 섀도, 애너글리프 타이틀. 상승=빨강/하락=파랑 (한국 관례).
- 한/영 완전 이중언어 (봇 이름·차트 해설·칭호까지 번역, 로비 토글).

## 2. 매치 구조 (~30분)

```
로비 → [차트 1 워밍업] → [2 변동성 입문] → [3 하락장] → [4 밈 대란] → [5 횡보 지옥] → [6 파이널: 레전드] → 최종 시상
```

- **6차트 리그전**, 차트당 5분(보통 템포 기준). 차트 사이 정산 쇼(호스트 진행 + 30초 자동 진행).
- **자본 리셋 모델**: 매 차트 시작 자본 1,000만 동일. 차트 종료 시 수익률 순위 → 포인트.
  초반 죽어도 다음 차트에서 새 출발 → 30분 내내 전원 유효.
- 인원: 8인 고정 — 인간 1~8 + 봇 자동 충원. 세 가지 입장: **혼자 연습**(봇 7) /
  **방 만들기**(4자 코드 발급) / **참가**(코드 입력).

### 2.1 포인트
| 순위 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 포인트 | 10 | 7 | 5 | 4 | 3 | 2 | 1 | 0 |

- **파이널(6번째) ×1.5** — 최대 15점, 역전각 보장.
- 라운드 동률: 수수료 적게 낸 쪽 우선, 그다음 참가 순서 (결정적 처리).
- 매치 동점: 파이널 차트 수익률 우선.

### 2.2 차트 라인업 — 실데이터 12종 (테마별 2종 풀에서 매치마다 추첨)

## 3. 차트 루프 (1차트 = 12회 의사결정)

### 3.1 틱 구조
- 원본: 실제 일봉 ~250개 → **60틱 OHLC 리샘플** (틱당 4~5거래일), 시작가 100 정규화.
- **12회 의사결정 창** (5틱마다 1회):
  - **락인 페이즈**: 주문 입력. 템포 3단계 — 보통 15초 / 빠름 8초 / 초스피드 5초.
    ⚡ **조기 락인**: 락인 버튼을 누르면 대기 없이 즉시 재생 (파티 템포 핵심 개선).
  - **재생 페이즈**: 캔들 5틱 라이브 재생 (보통 10초 / 6초 / 4초). 전원 포지션 고정 상태로 관전.
- ⚡ **첫 창은 깜깜이 배팅**: 정보 0에서 시초가 배팅 ("감으로 지르세요"). 5틱 프리뷰안은 A/B 대상.

### 3.2 주문 시스템
- 포지션은 **슬라이더 하나**: 숏 100% ← 현금 → 롱 100% (5% 단위) + 퀵버튼 5개
  (풀숏 / 숏 50 / 전량 현금화 / 롱 50 / 풀매수).
- **수수료**: 포지션 *변경분*에 0.5%. 락인 전에 예상 수수료 실시간 표시.
- 미변경 시 이전 포지션 유지 (수수료 없음).

### 3.3 손익 모델 (구현 정의)
- 가격 경로는 **종가 시퀀스**: p₀=100(첫 시가), 이후 각 틱의 종가. 틱 수익률 r = pₜ₊₁/pₜ - 1 (갭 포함).
- 평가액은 틱마다 E ← E × (1 + x·r) (x = 포지션 -1..+1). 일일 리밸런스 레버리지 ETF와 같은 단순 모델.
- ⚡ **강제 청산(마진콜)** — 기획에 없던 규칙: 한 틱 손실로 평가액이 -95% 이하가 될 경우
  (예: 숏 상태에서 밈 주식이 한 틱 +100% 폭등) 5%만 남기고 포지션 강제 종료 + 💥 연출.
  GME 풀숏 시 계좌가 수학적으로 음수가 되는 문제의 해법이자 파티게임 명장면 장치.
- ⚡ **캔들 = 손익 일치**: 캔들 i의 시가를 캔들 i-1의 종가로 체인 연결 (고저는 갭 범위 포함 확장).
  캔들 몸통이 곧 그 틱의 실제 수익률 — 화면과 손익이 1:1.

### 3.4 익명화
- 시작가 100 정규화, 종목명·날짜·거래량 숨김. y축은 로그 스케일(밈 주식 대응)이며
  **공개된 캔들 기준으로만** 스케일 산정 (전체 범위를 미리 잡으면 미래가 스포일러됨).

## 5. 정산 쇼 (차트 사이)

3중 공개 — 매 차트의 클라이맥스:
1. **차트 정체 공개**: 심볼 도장 스탬프 + 종목명 + 기간 + 한 줄 서사
   (예: "2020년 3월… 공포에 판 사람과 산 사람의 운명이 갈렸다").
2. **존버 벤치마크**: "첫 틱에 풀매수하고 가만히 있었다면 +34%" → 그보다 못 번 플레이어
   전원 굴욕 하이라이트 (📉 존버보다 못 벌었다). 전원이 이기면 축하 문구.
3. **정산표**: 순위·수익률·수수료·**스킬 점수**·획득/누적 포인트.

**스킬 점수** = 내 수익률 / 이론상 최대 수익률 (0~100%).
이론최대는 포지션 그리드(0.25 간격) DP로 수수료·청산 규칙까지 반영해 계산.

## 6. 최종 시상

- 포디움(2-1-3) + 색종이 + 팡파레 + 우승자 애너글리프 타이틀.
- **재미 칭호** (산정 규칙 확정):
  | 칭호 | 조건 |
  |---|---|
  | 🗿 존버왕 | 종합 상위 절반 중 총 포지션 변경량 최소 |
  | 👻 단타귀신 | 턴오버 최다 & 누적 수익 플러스 (없으면 턴오버 최다) |
  | 💸 증권사 VIP | 수수료 총액 최다 |
  | 🔮 역베천재 | 다수 반대 포지션으로 얻은 수익 최다 (+1%p 초과 시만) |
  | 🎣 바닥캐치 | 차트 최저점 ±2틱 내 매수(포지션 +0.2↑) 성공 최다 (1회 이상) |

- **결과 카드 복사**: 우승자·내 순위·차트별 성적을 클립보드로 — 공유가 바이럴 훅.
- 한 판 더 (새 시드로 차트 재추첨).

## 8. 기술 아키텍처

- **스택**: Vite + React + TypeScript + PeerJS. 108KB gzip. 정적 호스팅만으로 멀티 동작 (게임 서버 0대).
- **멀티플레이어 (v0.3)**: WebRTC P2P **호스트 권위** 스타 토폴로지.
  - 방 코드 4자 = PeerJS 피어 ID. 게스트는 호스트에만 연결, 호스트가 릴레이.
  - 결정성 활용: 차트/엔진이 전 클라이언트에 동일 → 호스트는 창마다 **체결 포지션 배열만**
    브로드캐스트(`play`), 각자 로컬 시뮬레이션 (메시지 초소형, 결과 완전 일치. IEEE754 부동소수점
    연산은 엔진처럼 연산 순서가 같으면 크로스 브라우저 결정적).
  - 진행 동기화: `phase`(락 시작) / `play`(체결) / `nextChart` / `rematch`. 게스트 타이머는
    표시용, 마감 권위는 호스트.
  - 조기 진행: 전원 락인 시 대기 없이 즉시 재생 (파티 템포).
  - **백그라운드 탭 내성**: rAF 정지 시 워치독 인터벌이 틱 확정을 대행, 뒤처진 게스트는
    play 버퍼 + 4배속 재생으로 캐치업.
  - 이탈 처리: 게스트 이탈 → 마지막 포지션 유지 + 📵 표시. 호스트 이탈 → 방 해산.
  - 봇은 호스트에서만 결정(미래 열람 방지 + 결정성 부담 제거), 빈자리 자동 충원.
- **데이터 파이프라인** (`scripts/build-charts.mjs`): Yahoo Finance 일봉 원본(data-raw/)
  → 60틱 리샘플 → 정규화 → 종가 체인 → 메타데이터(정체 공개용) → `src/data/charts.json`.
  종목 정체는 클라이언트에 포함되나 정산 전 UI 미노출 (파티게임 수준의 치팅 방어 ⚡ —
  서버 은닉은 멀티 버전에서).
- **엔진** (`src/engine/`): UI 라이브 재생과 일괄 시뮬레이션이 **같은 `RoundStepper`** 를 공유
  → 화면과 정산 불일치 원천 차단. vitest 14개 (수수료·청산·포인트·연속성·증분/일괄 일치).
- **렌더링**: 캔버스 캔들 차트 (로그 스케일, 도메인 스무딩, 성장 애니메이션, dpr 대응).
- **i18n** (`src/i18n.tsx`): ko/en 사전 + 봇/차트/칭호 전체, 브라우저 언어 자동 감지.
- **배포**: GitHub Pages (`npx gh-pages -d dist`, base `/chart-party/`).

## 9. 프로토타입 검증 결과 (v0.1 열린 질문의 답)

| 질문 | 결론 |
|---|---|
| 락인 15초가 쫄깃한가 | 솔로+봇에선 길다 → **조기 락인** 도입으로 해결. 멀티에선 "전원 락인 시 조기 재생"으로 일반화 |
| 수수료 0.5% 적정성 | 단타치타(매 창 뒤집기)가 횡보 차트에서 안정적으로 최하위 → 응징 강도 적절 |
| 보조지표 | v0.2는 캔들만. MA는 미결 (등락 전광판이 판단 재료 일부를 대체) |
| 차트 y축 | 전체 범위 선계산은 미래 스포일러 → 공개분 기준 로그 스케일 + 스무딩 확정 |
| 숏 × 밈 주식 | 계좌 음수 가능성 발견 → 강제 청산 규칙 신설 (테스트가 잡아낸 설계 구멍) |
| 갭 표시 | 시가-종가 몸통은 손익과 불일치 → 종가 체인 확정 |
